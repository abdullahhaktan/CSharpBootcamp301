## 💻 Proje Hakkında

Bu depo, C# programlama diline yeni başlayanlar için tasarlanmış bir eğitim kampının (Bootcamp) **giriş seviyesi** konularını ve alıştırmalarını içerir. Amacı, programlamanın temel mantığını ve C# dilinin basit sözdizimini (syntax) pratik uygulamalarla öğretmektir.

---

## ✨ Kapsanan Temel Konular

Bu eğitim kampı içeriği genellikle aşağıdaki en temel programlama kavramlarını kapsar:

### Programlama Temelleri
* **Giriş/Çıkış İşlemleri:** Konsol uygulamalarında kullanıcıdan veri alma ve ekrana çıktı verme (`Console.WriteLine`, `Console.ReadLine`).
* **Değişkenler ve Veri Tipleri:** C# dilindeki temel veri tipleri (`int`, `string`, `bool`, `double`).
* **Operatörler:** Aritmetik, atama, karşılaştırma ve mantıksal operatörlerin kullanımı.
* **Tip Dönüşümleri (Type Conversion):** Açık (explicit) ve kapalı (implicit) dönüşümler.

### Akış Kontrolü
* **Koşullu İfadeler:** `if`, `else if`, `else` blokları ve `switch` yapısı.
* **Döngüler (Loops):** Tekrarlayan görevler için `for`, `while`, `do-while` döngülerinin kullanımı.
* **Diziler (Arrays):** Tek boyutlu dizilerin tanımlanması ve elemanlarına erişim.

### Metotlar ve Fonksiyonlar
* **Temel Metot Tanımlama:** Parametresiz ve parametreli metotların oluşturulması.
* **Geri Dönüş Değeri:** Değer döndüren ve döndürmeyen metotlar.

# CSharpBootcamp301

**Beginner Level Training Camp Content for C# Programming Language**

---

## 💻 About the Project

This repository contains **entry-level** topics and exercises from a programming bootcamp designed for newcomers to the C# language. The goal is to teach the fundamental logic of programming and the basic C# syntax through practical examples.

---

## ✨ Core Topics Covered

This training content generally covers the most fundamental programming concepts:

### Programming Fundamentals
* **Input/Output Operations:** Receiving user input and printing output in console applications (`Console.WriteLine`, `Console.ReadLine`).
* **Variables and Data Types:** Basic data types in C# (`int`, `string`, `bool`, `double`).
* **Operators:** Usage of arithmetic, assignment, comparison, and logical operators.
* **Type Conversion:** Explicit and implicit type conversions.

### Flow Control
* **Conditional Statements:** `if`, `else if`, `else` blocks, and the `switch` statement.
* **Loops:** Using `for`, `while`, and `do-while` loops for repetitive tasks.
* **Arrays:** Defining and accessing elements of one-dimensional arrays.

### Methods and Functions
* **Basic Method Definition:** Creating methods with and without parameters.
* **Return Value:** Methods that return a value and those that do not (`void`).

---

## 🚀 How to Run

This repository typically contains multiple simple Console Application projects.

1.  **Cloning the Project:**
    ```bash
    git clone [https://github.com/abdullahhaktan/CSharpBootcamp301](https://github.com/abdullahhaktan/CSharpBootcamp301)
    cd CSharpBootcamp301
    ```

2.  **Opening the Projects:**
    * Open the root directory's **`.sln`** (Solution) file using **Visual Studio** or Visual Studio Code.
    * Each folder contains the sample project for its respective topic.

3.  **Building and Running:**
    * Build the solution in Visual Studio (`Build Solution` or F6).
    * Set the project you wish to run as the **`Startup Project`** and press **F5** to start the application.
